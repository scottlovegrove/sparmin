- **Fixed a crash on launch on older watches.** On devices running Connect IQ 3.1
  — the fenix 5, 5S, 5X and Chronos, Forerunner 645 and 935, vívoactive 3, and
  the D2 Delta and Descent Mk1 — the app closed the instant you opened it. It was
  reaching for an activity type that only exists on newer watches; it now uses a
  form every supported watch understands, so it opens and records as expected.
