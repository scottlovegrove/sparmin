version: 0.7.2
summary: Sessions that send themselves now include the time between stations, so a linked visit reads the same as one imported from a file.
---

- **The time between stations is sent too.** A session that uploaded itself
  listed only the places you stopped, so the walks, showers and standing about
  in between simply weren't there — the same visit imported from Garmin as a
  file showed them. Both now describe the whole visit, gap for gap.
- Nothing about the recording changes: the activity saved to your watch and to
  Garmin Connect already timed the transitions, and always did.
- Sessions already in the companion are unaffected. Import that visit's file if
  you want its gaps filled in.
