---

- **Fixed: the linking code was unreadable on larger watches.** It was drawn in a
  font that has no letters in it, so a code like `VRYV-9TQF` reached the screen
  as `R -9 F` — spaced out exactly as if nothing were missing. If you tried to
  link and Sparmin told you the code was wrong, this is why: the code was right,
  the screen was not showing it. Nothing else was affected, and codes generated
  before now were never wrong.
